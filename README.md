# TopoAI — прототип анализа топографической съёмки

Приложение загружает изображения и PDF топопланов, показывает первую страницу, позволяет обвести контур участка, запускает OCR и сохраняет распознанные числовые подписи в CSV.

## Важно о точности
Это **стартовый прототип, а не готовая геодезическая система**:
- OCR находит числовые подписи, но сам по себе не умеет надёжно отличать высотные отметки от номеров зданий, отметок коммуникаций, координат и других чисел.
- Для точного расчёта площади нужна геопривязка или калибровка по известному расстоянию. Масштаб `1:N` недостаточен, если скан менял размер или неизвестен DPI.
- В текущей версии обводка контура — вспомогательный интерфейс; перед использованием площади в документации контур и результат нужно проверить. Для инженерного применения следует использовать исходные координаты/векторные данные (например, DXF, GeoTIFF, SHP) и контроль геодезиста.
- Горизонтали и их высоты требуют отдельного алгоритма распознавания линий/подписей и интерполяции цифровой модели рельефа. Эта версия не восстанавливает полноценную 3D-поверхность.

## Запуск локально
1. Установите Python 3.10–3.12.
2. Установите системный Tesseract OCR:
   - Windows: установите Tesseract и добавьте его в PATH.
   - Ubuntu/Colab: `sudo apt-get install tesseract-ocr tesseract-ocr-rus`
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите:
   ```bash
   streamlit run app.py
   ```

## Следующий этап для более точной модели
1. Собрать размеченный набор топопланов разных масштабов/качества.
2. Разметить высотные подписи, горизонтали, границы участка, координатную сетку и условные знаки.
3. Обучить детектор (например, YOLO) для подписей и границ; OCR использовать для чтения чисел.
4. Геопривязать изображение по координатной сетке или минимум двум контрольным точкам.
5. Построить ЦМР/DEM из горизонталей и отметок, затем вычислять уклоны, профили и объёмные показатели с оценкой погрешности.

## Публикация сайта в интернете через Streamlit Community Cloud

1. Распакуйте ZIP-архив.
2. Создайте репозиторий GitHub и загрузите в корень файлы `app.py`, `requirements.txt`, `packages.txt`, `README.md` и `TopoAI_Colab.ipynb`.
3. Откройте https://share.streamlit.io/ и войдите через GitHub.
4. Выберите **Create app**, укажите репозиторий, ветку `main` и путь к главному файлу `app.py`.
5. Нажмите **Deploy**. После сборки Streamlit выдаст ссылку на сайт.

Не загружайте конфиденциальные планы в публичный репозиторий. Текущая версия — прототип: площадь участка и распознавание отметок требуют ручной проверки.
